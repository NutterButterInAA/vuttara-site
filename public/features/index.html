Features

Practical tools for everyday browsing, performance, privacy, and recovery.

Tabs and sessions

Horizontal or vertical tabs, pinning, sleeping tabs, closed-tab recovery, crash recovery, and startup controls.

Profiles

Multiple local profiles with separate browser data, guest mode, profile backup, and profile reset.

Privacy

Tracker protection, private tabs, permission rules, encrypted credentials, and category-based data clearing.

Browser tools

Find in page, zoom, print, fullscreen, context menus, bookmarks, history, and download management.

Performance

Memory Saver, background throttling, sleeping exceptions, audio protection, and tab performance information.

Updates

Stable and beta channels, release notes, update skipping, background downloads, and restart-to-install.
