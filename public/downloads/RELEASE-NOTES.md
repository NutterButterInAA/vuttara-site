# Vuttara 3.2.31

Released: 2026-08-01

## Improvements

- Added mute and unmute controls to horizontal tabs.
- Added mute and unmute controls to normal vertical tabs.
- Added mute and unmute controls to the vertical hover and overlay tab drawer.
- Fixed saving and restoring multiple open tabs.
- Restored the correct tab order and active tab at startup.
- Removed mojibake and malformed characters from Quick Settings and browser-owned context menus.

## Release validation

- Built from the confirmed published Vuttara 3.2.30 baseline.
- Exact installer, blockmap, and latest.yml artifacts were hash-validated.
- The installer passed clean isolated-user installation, launch, shutdown, uninstall, and cleanup testing.
