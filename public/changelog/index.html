Vuttara 3.2.32

August 2, 2026

  • Added New Tab Page Customization V1 with solid colors, uploaded backgrounds, cover/contain/stretch fitting, darkness control, visibility controls, and Google, Bing, or DuckDuckGo search.
  • Added shortcut creation, editing, removal, drag reordering, uploaded icons, favicon fallback, and compact, normal, or spacious tile sizing.
  • Saved new-tab customization independently for each normal profile while preventing private browsing from permanently changing normal-profile settings.
  • Added narrowly scoped, user-initiated Google and Firebase sign-in popup support using managed authentication windows.
  • Preserved ordinary popup, advertising, redirect, creator-dashboard, and aggressive unwanted-popup protection.

Vuttara 3.2.31

August 1, 2026

  • Added mute and unmute controls across horizontal tabs, standard vertical tabs, and the vertical hover/overlay tab drawer.
  • Repaired startup restoration so multiple saved normal tabs reopen correctly while preserving profile separation and private-tab exclusions.
  • Removed corrupted and mojibake characters from Quick Settings and other browser context menus.

Vuttara 3.2.30

July 31, 2026

  • Added production-ready Netflix protected-media compatibility using CastLabs Electron for Content Security and Widevine readiness.
  • Added Netflix protected-media permission handling, Netflix-specific browser identity handling, and the required Content Blocking exemptions.
  • Added production streaming VMP signing and verification support, with actual Netflix title playback validation.
  • Preserved Content Blocking V1, the interactive update prompt, Full Settings auto-save, Daily Tools, bookmark modernization, toolbar customization, profiles, tabs, downloads, permissions, and updater behavior.
  • Extension Support V1 remains paused and is not included.

Vuttara 3.2.29

July 30, 2026

  • Content Blocking V1 adds Full Settings controls for advertising, trackers, popups, and experimental YouTube advertisement blocking with automatic save-status feedback.
  • Unsolicited popup windows, popup tabs, popunders, click-anywhere advertising redirects, and server redirects are blocked, including rotating Lekuluent domains.
  • Creator-dashboard popouts always open as separate resizable mini windows with a small address field while preserving the originating profile and login session.
  • YouTube ad blocking remains experimental and best effort, with expanded response sanitizing, advertisement-state detection, skip controls, and accelerated muted advertisement handling.

Vuttara 3.2.28

July 30, 2026

  • Full Settings now saves changes automatically after a short debounce, with clear saving, success, and failure feedback.
  • The manual Save settings button has been removed while profile-specific settings and immediate control updates remain intact.
  • Daily Tools now opens from a titlebar control immediately beside the native window buttons instead of using a floating browser-content trigger.
  • Daily Tools remains a live overlay above webpages and uses a compact icon-only titlebar control on narrow windows.

Vuttara 3.2.27

July 30, 2026

  • Bookmark-bar folders now open as live overlays above webpages without shifting or freezing page content.
  • Added modern bookmark and folder Properties windows plus Vuttara-styled right-click editing throughout the bookmark bar, nested folders, and Bookmarks Manager.
  • Modernized the bookmark bar with responsive overflow, favicons, folder colors and counts, quick-add controls, drag reordering, and clearer drop cues.
  • Expanded Bookmarks Manager with search, list and grid views, sorting, multi-select, bulk actions, undo, duplicate and recent views, and HTML/JSON import and export.

Vuttara 3.2.26

July 29, 2026

  • Modernized browser chrome, menus, Settings, spacing, and interaction flow with lower-cost visual effects.
  • Added an adaptive toolbar with responsive overflow, normal and compact density, persistent pinning, right-click unpinning, and a Customize toolbar page.
  • Site Privacy now overlays the live webpage without shifting or freezing video, animation, audio, or page timers.
  • Downloads now show active count, progress, speed, remaining time, and filenames from a compact toolbar hover card.

Vuttara 3.2.24

July 29, 2026

  • Daily Tools now uses a compact overlay tab that stays above webpages without moving page content.
  • Visible-text translation now works in the current page and includes restore-original-text controls.
  • The translation language library includes Klingon and uses source-language hints for more reliable results.
  • Browser and website text encoding problems were repaired, including corrupted icons, punctuation, and status text.

Vuttara 3.2.23

July 28, 2026

  • Restored canonical Windows Default Apps registration for web links and HTML files.
  • Default-browser settings now open directly to Vuttara.
  • External links now open in the existing Vuttara window, including links received during startup.
  • Uninstalling Vuttara removes its Windows application and protocol registration.
